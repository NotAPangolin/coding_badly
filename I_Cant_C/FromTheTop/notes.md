Course Objectives

Upon successful completion of this course, students will have demonstrated the following abilities:
· The knowledge to use the basic programming elements of the C++programming language.
· The ability to develop algorithms to solve simple application problems.
· The ability to transform algorithms into C++ programs, using top-down modular program development.
· The ability to understand and correct syntax errors generated by a compiler.
· The ability to diagnose and correct logic errors in computer programs.

Relationship of Course to Student Outcomes:
· Computing Accreditation Commission:
o Outcome (a): Students apply their knowledge of logic, mathematics, and basic computer instructions to develop problem solving and programming skills.
o Outcome (b): Students learn how to analyze a problem and recognize the input, output, and algorithm requirements for a solution.
o Outcome (c): Students learn to design, implement and test computer programs based on the identified requirements.
o Outcome (i): Students learn to use a text editor for creating programs, a compiler for translating programs, and how to execute programs on a computer.
· Engineering Accreditation Commission:
o Outcome (a): Students learn to apply their knowledge of logic, mathematics, and elementary programming to develop problem solving skills using the C programming language.
o Outcome (c): Students learn how to analyze a problem and design a program to meet requirements within realistic input and output constraints.
o Outcome (k): Students learn to use current editors and compilers, and acquire debugging skills for developing correctly executing computer programs.

Required Texts

Topics Covered

· Identifier names and data types, assignment statements, and main function organization

· Functions

· Formatted input/output
· File processing
